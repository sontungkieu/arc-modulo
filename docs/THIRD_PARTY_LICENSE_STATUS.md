# Trạng thái license của source upstream

Kiểm tra trên đúng bốn commit được ghim ngày 2026-08-15:

| Upstream snapshot | License file trong tree |
|---|---|
| DAS | `upstream/das/LICENSE` — MIT |
| Null-TTA | `upstream/null-tta/LICENSE` — MIT |
| FK Steering | Không thấy license file trong pinned tree |
| FK Correctors | Không thấy license file trong pinned tree |

Việc repository upstream công khai **không tự động đồng nghĩa** với quyền tái
phân phối rộng rãi. Hai branch không có license được giữ nguyên provenance,
commit history và URL tác giả để phục vụ nghiên cứu/reproduction; không có tuyên
bố rằng chúng mang license của phần wrapper. Nếu phát hành lại ngoài phạm vi
nghiên cứu cá nhân, cần xin phép tác giả hoặc cập nhật theo license upstream mới.
